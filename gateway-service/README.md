# API Gateway

Из корня проекта запусти все сервисы через зависимости Gateway:

```bash
docker compose up -d --build gateway-service
curl -f http://localhost:8080/manage/health
```

Публичные маршруты варианта 2 доступны под `/api/v1`. Gateway связывается с тремя
сервисами по HTTP. Для локального запуска по умолчанию используются Reservation
на `localhost:8070`, Payment на `localhost:8060` и Loyalty на `localhost:8050`.

При создании брони Gateway читает скидку до регистрации новой брони. Платёж
выражен целым числом: дробная часть после скидки округляется до ближайшей
целой денежной единицы, половины округляются вверх. Публичный ответ отдаёт
скидку числом, как в примере OpenAPI и проверках Postman.

Отмена сначала проверяет владельца, затем меняет статус брони, отменяет платёж
и снимает бронь с учёта в Loyalty. Повторный DELETE безопасно завершает
оставшиеся шаги. При создании Gateway старается отменить уже подтверждённые
операции, если следующий шаг завершился ошибкой. POST автоматически не
повторяется. Тайм-аут записи может означать, что сервис успел сохранить данные;
для гарантированного восстановления после таких сбоев нужна отдельная
идемпотентность создания и постоянное хранение состояния операции.

Локальные тесты Gateway из его каталога:

```bash
.venv/bin/python -m unittest discover -s tests -v
```

Коллекция варианта 2 из корня проекта при чистой тестовой базе:

```bash
npx --yes newman@6.2.1 run v2/postman/collection.json -e v2/postman/environment.json
```
